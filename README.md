# shop-updates — مصدر التحديث التلقائي

مستودع خاص يخدم نظام التحديث التلقائي الصامت لبرنامج «نظام المبيعات
والمُرتجعات — محل الكمبيوتر».

## الملفان اللذان يقرأهما البرنامج
- `version.txt` — رقم أحدث إصدار فقط (مثال: `2.4`)
- `main.py` — نسخة البرنامج الكاملة الجديدة

## عند إصدار تحديث جديد
1. عدّل `main.py` في هذا المستودع بالنسخة الجديدة (وغيّر داخلها
   `VERSION` إلى الرقم الجديد)
2. عدّل `version.txt` إلى نفس الرقم الجديد
3. كل الأجهزة سترى شريطاً أصفر «🔔 يتوفر تحديث جديد — الإصدار [رقم]» عند
   فتح البرنامج (ومنذ 2.3: خلال 30 دقيقة كحد أقصى حتى والبرنامج مفتوح)،
   والمدير يثبّته بزر واحد — والبائع يرى «راجع المدير» فقط

## سجل الإصدارات
- 2.1: إصلاح منطق ظهور شريط وزر التحديث الصارم (مقارنة أرقام حقيقية)
- 2.2: إضافة نافذة «ℹ️ عن البرنامج» (الإصدار، آخر تحديث، حالة الفحص،
  الساعة، المستخدم، مجلد البيانات) — إضافة فقط دون أي تغيير آخر
- 2.3: فحص دوري صامت كل 30 دقيقة (الشريط يظهر دون إعادة تشغيل) + نافذة
  «عن البرنامج» من قائمة المستخدم لكل الأدوار مع سطر عدد الأرشيف + عودة
  زر «فحص التحديثات الآن» (بالشريط الأصفر وقائمة المستخدم) + أرشيف
  الإصدارات versions_archive (سجل تاريخي كامل بلا حذف + استعادة آمنة
  تحفظ الحالي أولاً) — إصلاح وإضافة فقط دون أي تغيير آخر
- 2.4: دور «أدمن» جديد أعلى من المدير (حساب admin محمي — لا يُعدَّل ولا
  يُوقف إلا من الأدمن نفسه، والشريط الجانبي بنفسجي له) + يوم عمل حقيقي
  (زر «▶️ بدء يوم جديد»، الإغلاق يطابق اليوم المفتوح لا تاريخ الجهاز،
  الاستمرار عليه بعد منتصف الليل 🌙، منع تكرار أو رجوع التاريخ) + سلة
  المحذوفات مع زر «♻️ آخر حذف» واستعادة كاملة + قفل الجلسة 🔒 وقفل
  الدخول 60 ثانية بعد 5 محاولات فاشلة + فرز رؤوس الجداول الثمانية
  بالنقر وصفوف متناوبة وعدادات «المحدد/المجموع» + حد أدنى لكلمات المرور
  حسب الدور + فلترة إدخال الأرقام بالعربية ٠-٩ في كل الحقول — إضافات
  وإصلاحات فقط دون حذف

## ملاحظات

  البرنامج يعمل طبيعياً
- التوكن مطلوب فقط لأن المستودع خاص — لا يظهر في أي واجهة بالبرنامج
