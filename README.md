# shop-updates — مصدر التحديث التلقائي

مستودع خاص يخدم نظام التحديث التلقائي الصامت لبرنامج «نظام المبيعات
والمُرتجعات — محل الكمبيوتر».

## الملفات التي يقرأها البرنامج
- `version.txt` — رقم أحدث إصدار فقط (مثال: `2.6`)
- `main.py` — نسخة البرنامج الكاملة الجديدة
- `changelog.txt` — ملاحظات الإصدارات (منذ 2.5) — يعرضها زر
  «📄 ما الجديد؟» في نافذة الموافقة على التحديث

## عند إصدار تحديث جديد
1. عدّل `main.py` في هذا المستودع بالنسخة الجديدة (وغيّر داخلها
   `VERSION` إلى الرقم الجديد)
2. عدّل `version.txt` إلى نفس الرقم الجديد
3. أضف قسم ملاحظات الإصدار في أول `changelog.txt` (قسم يبدأ بسطر
   أول كلمته رقم الإصدار مثل «2.7 — ...»)
4. كل الأجهزة سترى شريطاً أصفر «🔔 يتوفر تحديث جديد — الإصدار [رقم]»
   عند فتح البرنامج (ومنذ 2.3: خلال 30 دقيقة كحد أقصى حتى والبرنامج
   مفتوح)، والمدير يوافق صراحة بنافذة التحديث (منذ 2.5) ثم زر واحد —
   والبائع يرى «راجع المدير» فقط

## سجل الإصدارات
- 2.1: إصلاح منطق ظهور شريط وزر التحديث الصارم (مقارنة أرقام حقيقية)
- 2.2: إضافة نافذة «ℹ️ عن البرنامج» (الإصدار، آخر تحديث، حالة الفحص،
  الساعة، المستخدم، مجلد البيانات) — إضافة فقط دون أي تغيير آخر
- 2.3: فحص دوري صامت كل 30 دقيقة (الشريط يظهر دون إعادة تشغيل) + نافذة
  «عن البرنامج» من قائمة المستخدم لكل الأدوار مع سطر عدد الأرشيف + عودة
  زر «فحص التحديثات الآن» (بالشريط الأصفر وقائمة المستخدم) + أرشيف
  الإصدارات versions_archive (سجل تاريخي كامل بلا حذف + استعادة آمنة
  تحفظ الحالي أولاً) — إصلاح وإضافة فقط دون أي تغيير آخر
- 2.4: دور «أدمن» جديد أعلى من المدير (حساب admin محمي — لا يُعدَّل ولا
  يُوقف إلا من الأدمن نفسه، والشريط الجانبي بنفسجي له) + يوم عمل حقيقي
  (زر «▶️ بدء يوم جديد»، الإغلاق يطابق اليوم المفتوح لا تاريخ الجهاز،
  الاستمرار عليه بعد منتصف الليل 🌙، منع تكرار أو رجوع التاريخ) + سلة
  المحذوفات مع زر «♻️ آخر حذف» واستعادة كاملة + قفل الجلسة 🔒 وقفل
  الدخول 60 ثانية بعد 5 محاولات فاشلة + فرز رؤوس الجداول الثمانية
  بالنقر وصفوف متناوبة وعدادات «المحدد/المجموع» + حد أدنى لكلمات المرور
  حسب الدور + فلترة إدخال الأرقام بالعربية ٠-٩ في كل الحقول — إضافات
  وإصلاحات فقط دون حذف
- 2.5: القاعدة الذهبية لتخطيط كل النوافذ المنبثقة (لا قصّ للأزرار أبداً:
  شريط الأزرار السفلي يُحزم أولاً ثم الرأس ثم المحتوى يتمدد + تمركز وسط
  الشاشة + سقف الشاشة − 80 بكسل + فحص ذاتي يرفع الأبعاد + أحجام جديدة
  لأرشيف الإصدارات وتفاصيل اليوم وسلة المحذوفات والمعاينة) + التحديث
  بإعلام وموافقة صريحة (نافذة «الإصدار الحالي ← الجديد» + زر «📄 ما
  الجديد؟» يعرض قسم الإصدار من changelog.txt + لا تنزيل إلا بزر «✅ نعم،
  ثبّت التحديث الآن» + «❌ لا، لاحقاً» لا يفعل شيئاً + تعطيل التثبيت حتى
  تأكيد فقدان السلة غير المحفوظة) + إعادة تشغيل تلقائية آمنة بعد
  التثبيت (إطلاق الجديدة أولاً ثم الخروج النظيف — لا تُمس البيانات
  أبداً) — إضافات وإصلاحات فقط دون حذف
- 2.6: إغلاق ثغرات الغش الوظيفية: ربط المرتجع بعملية البيع الأصلية (صف
  «العملية المُرجَعة» الإلزامي + الكمية داخل المتبقي + السعر مقفل بسعر
  الأصل + عمود original_op_id وشارة «↩ مرجع» في كل الجداول + الربط
  يُحفظ ويُستعاد عبر سلة المحذوفات) + لوحة تنبيهات الإدارة بعد الدخول
  (بطاقة صفراء/حمراء بإحصاءات آخر 7 أيام: حذف/إعادة فتح يوم/محاولات
  دخول فاشلة + زر عرض التفاصيل) + توقيع تسلسلي لسجل التدقيق (prev_hash
  لكل سجل + زر «🧪 فحص سلامة السجل» يكشف أي تعديل أو حذف أو اقتطاع) —
  والتحصين التقني: وضع WAL للقاعدة (أمان انقطاع الكهرباء + توحيد كامل
  قبل كل نسخة) + 4 فهارس تسريع + بوابة بصمة كود البرنامج (sha256 عند
  كل إقلاع — التعديل اليدوي خارج النظام = شاشة حمراء لا تجاوز إلا
  باعتماد المالك بكلمة سر الأدمن، والتحديث النظامي يحدّثها تلقائياً) +
  ضغط النسخ اليومية والفورية zip (والشهرية .db كما هي مع توافق خلفي
  كامل) + زر «🧪 فحص سلامة قاعدة البيانات» — إضافات فقط دون حذف نقي
